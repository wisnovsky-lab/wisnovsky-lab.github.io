Connect to GitHub

Changes you make here are saved straight to the website. To do that, this page needs a GitHub access token. You only set it up once on each computer.

  1. You need a GitHub account that's a member of the wisnovsky-lab organization. Ask a lab owner to invite you if you aren't one yet.
  2. Open GitHub's new token page and fill it in:
    • Token name: Lab website editor
    • Resource owner: wisnovsky-lab
    • Expiration: 1 year is fine
    • Repository access: Only select repositories → wisnovsky-lab.github.io
    • Permissions: Repository permissions → Contents → Read and write
  3. Click Generate token, copy the token (it starts with github_pat_) and paste it below.
It stays in this browser and is only ever sent to GitHub.

If GitHub says the token is waiting for approval, an owner of the organization can approve it under Organization settings → Personal access tokens → Pending requests.

Update the website

Add or change an entry and click Save. The website updates about a minute later.
